## 三、深度探索关键发现

1. **版本控制/回滚已具备**：`prompt_versions` 表 + `routers/prompts.py::rollback_prompt`，编辑/重置均归档旧内容，每 key 保留 ≤50 历史版本。需求 4「版本控制与回滚」**已完成**，无需重做。
2. **模板校验已具备**：`routers/prompts.py::_validate_prompt_content` 校验 `{shared:NAME}` 引用有效性、禁止静默删除默认模板关键变量（可用 `force=true` 跳过）。
3. **真实注入漏洞（R1）**：`render_prompt` 旧实现对每个变量单独 `re.sub` 并**顺序扫描整段结果**。先插入的变量值若包含另一变量名（如用户内容写 `{GLOBAL_FACTS}`），会在后续轮次被二次替换 —— 用户输入可「借用」其它上下文槽位注入数据。这是可证实的提示词注入/数据串味缺陷。
4. **安全能力缺失（R2）**：注入路径对变量值不做任何净化，用户内容中的 `{shared:...}`/`__VAR__` 元标记与邮箱/手机/身份证/密钥等敏感信息原样进入 LLM。
5. **上下文组装无预算（R3）**：各 workflow 自行 `.replace` 注入 `SUMMARY/CONTEXT/GLOBAL_FACTS/OUTLINE/CHART_INSTRUCTIONS`，无统一入口、无 Token 上限、无优先级截断，长目录/长事实易撑爆上下文窗口且截断不可控。

## 五、增强优化清单

- **统一模板定义/命名**：沿用既有 `_reg(KEY, category, label, content)` 三段式注册；新增模块不破坏既有命名。
- **版本控制与回滚**：复用既有 `prompt_versions`（已满足需求 4）。
- **统一变量注入 + Token 预算**：新增 `app/services/ai/prompts/_context.py::assemble_prompt_context`，按 `DEFAULT_PRIORITIES`（全局事实 100 > 评分 95 > 概述 90 > 目录 85 > 图表指令 80 …）组装，超 `max_tokens` 时高优先级保留、边界片段部分截断、更低优先级整体丢弃（宁缺毋假）。`estimate_tokens` 以 CJK 按字、其余 4 字≈1 token 粗算。
- **统一输出约束**：既有 `SHARED_OUTPUT_SPEC` 已约束「纯净 JSON、禁代码围栏」；本批未改动。
- **AI 调用优化**：注入净化为 opt-in（`sanitize`/`desensitize`），默认关闭以零回归；高风险链路可显式 `render_prompt_safe`。
- **跨模块安全**：新增 `_security.py`，与图表管线格式零冲突（JSON 载荷中的 `{` `}` 不被误伤，验证见测试）。
- **敏感信息脱敏 / 注入防范**：见下。

## 六、修复项清单（代码依据）

### G1 — 跨变量注入（单遍替换）
`app/services/ai/prompts/_registry.py::render_prompt`（L138 起）：
- 改为**一次性构建所有变量名的合并正则** `\{ (alt) \}|__ (ALT) __`，单次 `re.sub` 完成；插入的值不再被二次扫描，根除跨变量注入。
- 保留大小写不敏感（`IGNORECASE`）、`{var}`/`__VAR__` 双形态、`None` 值保留占位符、`BUG-FIX-44` 的 lambda 固定字符串（防反向引用误解释）、残留占位符告警。

### G2 — 元标记中和 + 敏感信息脱敏
新增 `app/services/ai/prompts/_security.py`：
- `neutralize_meta_markers`：中和 `{shared:NAME}`、`__VAR__`、`{var}` 元标记；**不触碰真实 JSON 对象**（如 `{"type":"flowchart"}` 因含冒号/引号与单 token 形态不符而保留），避免破坏图表 JSON 载荷。
- `desensitize_sensitive_info`：掩码邮箱 / 中国大陆手机 / 18 位身份证 / `ENC:` 密钥 / `sk-`、`api_key=` 通用密钥。
- `sanitize_prompt_value` / `wrap_user_data`：组合净化与数据边界包裹。

### G2 接线
- `render_prompt(template, *, sanitize=False, desensitize=False, **kwargs)`：两开关 opt-in，默认关闭（**向后兼容**，既有 16+ 项提示词测试全过）。
- 新增 `render_prompt_safe(template, **kwargs)`：`sanitize=True` 的推荐入口，供注入用户内容的调用方使用。
- `app/services/ai/prompts/__init__.py`：导出 `render_prompt_safe`、`neutralize_meta_markers`、`sanitize_prompt_value`、`desensitize_sensitive_info`、`assemble_prompt_context`、`estimate_tokens`、`DEFAULT_PRIORITIES`。
