# 行业树模块设计方案（商业化标准版）

> **版本**：v1.0
> **更新日期**：2026-07-05
> **关联文档**：《PRD v1.0》《技术架构文档》《行业知识库模块》
> **设计目标**：构建一套**可扩展、可维护、AI驱动**的行业树（Industry Tree）模块，支持用户按需生成行业细分节点，并供项目创建、知识库检索、提示词匹配等模块统一调用。


## 一、模块概述

### 1.1 什么是行业树

行业树是一个**多层级、动态演进的行业分类体系**，将建筑工程领域的行业知识组织为“根领域 → 细分行业 → 专业/专项”的三级树状结构。每个节点不仅是分类标签，更是一个可承载**知识库条目、提示词模板、评分标准**的上下文容器。

### 1.2 核心价值

| 能力            | 说明                                                         |
| --------------- | ------------------------------------------------------------ |
| **结构化分类**  | 将散落的12个行业知识库归入统一树形分类，消除重复与模糊       |
| **AI 驱动扩展** | 用户选定节点后，AI 自动生成合理的子节点，避免人工维护成本    |
| **跨模块共享**  | 项目创建、知识库管理、提示词匹配、评分点识别均可引用同一棵树 |
| **商业级控制**  | 支持版本追踪、启用/禁用、引用计数、批量操作                  |

### 1.3 与现有12行业知识库的映射关系

| 现有知识库        | 行业树中的位置                  |
| ----------------- | ------------------------------- |
| 通用技术服务      | 专项工程 → 通用技术服务         |

| 弱电智能化        | 专项工程 → 电子与智能化工程     |

| 市政/园林         | 市政工程 → 市政园林绿化         |
| 设备采购安装      | 专项工程 → 设备采购安装         |

## 三、数据模型（数据库设计）

### 3.1 表结构：`industry_tree`

```sql
CREATE TABLE industry_tree (
    id TEXT PRIMARY KEY,                          -- 可读ID，如 "construct_building_residential"
    name TEXT NOT NULL,                           -- 节点名称（中文）
    name_en TEXT,                                 -- 英文名称（国际化预留）
    parent_id TEXT,                               -- 父节点ID，根节点为 NULL
    level INTEGER NOT NULL,                       -- 层级：1/2/3
    description TEXT,                             -- 节点描述
    prompt_hint TEXT,                             -- AI生成时的额外约束（可选）
    icon TEXT,                                    -- 图标名称（前端渲染用）
    knowledge_base_ids JSON,                      -- 关联的知识库ID列表（数组）
    default_scoring_items JSON,                   -- 该行业默认的技术评分项（数组）
    is_active BOOLEAN DEFAULT 1,                  -- 启用/禁用（软删除）
    is_ai_generated BOOLEAN DEFAULT 0,            -- 是否由AI生成（区别于种子数据）
    order_index INTEGER DEFAULT 0,                -- 同级排序
    reference_count INTEGER DEFAULT 0,            -- 被项目引用的次数（自动维护）
    created_by TEXT DEFAULT 'system',             -- 创建人（系统/用户）
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(parent_id) REFERENCES industry_tree(id) ON DELETE CASCADE
);

-- 创建索引以加速查询
CREATE INDEX idx_industry_tree_parent_id ON industry_tree(parent_id);
CREATE INDEX idx_industry_tree_level ON industry_tree(level);
CREATE INDEX idx_industry_tree_is_active ON industry_tree(is_active);
CREATE INDEX idx_industry_tree_order_index ON industry_tree(order_index);

-- 使用触发器自动维护引用计数（简化版）
-- 实际使用中可通过 Project 表的 industry_tree_id 关联，用程序计算
```

### 3.2 核心字段说明

| 字段                    | 用途                                                         | 商业化关键点                             |
| ----------------------- | ------------------------------------------------------------ | ---------------------------------------- |
| `id`                    | 唯一标识，采用语义化编码（如 `construct_building_residential`） | 便于跨模块引用，不需要查表即可理解含义   |
| `knowledge_base_ids`    | 关联该行业对应的知识库条目ID                                 | 行业树与知识库双向打通，检索时优先匹配   |
| `default_scoring_items` | 该行业默认的技术评分项模板                                   | 新建项目时自动预填充评分点               |
| `reference_count`       | 被项目引用的次数                                             | 防止误删被引用的节点，商业级数据保护     |
| `is_ai_generated`       | 区分种子数据和AI生成数据                                     | 允许用户重置AI生成内容，而不影响基础骨架 |
| `is_active`             | 软删除                                                       | 保留数据历史，可恢复                     |

### 4.2 Pydantic 模型定义

```python
# backend/app/models/industry.py
from pydantic import BaseModel, Field
from typing import List, Optional
from datetime import datetime

class IndustryNodeBase(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)
    name_en: Optional[str] = None
    description: Optional[str] = Field(None, max_length=500)
    prompt_hint: Optional[str] = Field(None, max_length=500)
    icon: Optional[str] = None
    knowledge_base_ids: List[str] = Field(default_factory=list)
    default_scoring_items: List[Dict] = Field(default_factory=list)
    order_index: int = 0

class IndustryNodeCreate(IndustryNodeBase):
    parent_id: Optional[str] = None
    level: Optional[int] = None  # 自动计算

class IndustryNodeUpdate(BaseModel):
    name: Optional[str] = None
    name_en: Optional[str] = None
    description: Optional[str] = None
    prompt_hint: Optional[str] = None
    icon: Optional[str] = None
    knowledge_base_ids: Optional[List[str]] = None
    default_scoring_items: Optional[List[Dict]] = None
    is_active: Optional[bool] = None
    order_index: Optional[int] = None

class IndustryNode(IndustryNodeBase):
    id: str
    parent_id: Optional[str] = None
    level: int
    is_active: bool
    is_ai_generated: bool
    reference_count: int
    created_by: str
    created_at: datetime
    updated_at: datetime
    
    # 嵌套子节点（用于前端树渲染）
    children: List['IndustryNode'] = Field(default_factory=list)

class IndustryTreeNode(IndustryNode):
    """树节点（包含children递归）"""
    children: List['IndustryTreeNode'] = Field(default_factory=list)
```

## 六、AI 生成提示词设计

### 6.1 生成子节点提示词（`generate_children`）

```markdown
### 角色
你是一位资深的工程项目分类专家，熟悉中国建设工程行业分类标准（GB/T 50841-2013）及建筑工程领域的专业技术划分。

### 任务
为指定的行业分类父节点生成 {count} 个合理的、直接子级的专业领域分类。

### 父节点信息
- 名称：{parent_name}
- 层级：第 {parent_level} 级
- 描述：{parent_description}

### 生成规则
1. 子节点必须属于父节点的直接下级（二级或三级）
2. 每个子节点名称：4-10 个汉字，专业、具体
3. 每个子节点需包含简要描述（20-50 字）
4. 子节点之间应互斥、不重叠
5. 名称避免使用“其他”、“综合”等空泛词汇
6. 若父节点已是第三级，返回空数组（不继续生成为第四级）

### 输出格式
只返回合法的 JSON 数组：
[
  {{ "name": "子节点名称", "description": "子节点描述" }},
  ...
]

### 约束
- 若父节点层级已达最大深度，返回空数组 []
- 直接返回 JSON，不要 Markdown 代码块，不要解释文字
```

### 7.3 useIndustryTree Hook

```tsx
// frontend/src/hooks/useIndustryTree.ts
import { useEffect, useState } from 'react';
import { api } from '@/api';
import { IndustryNode, IndustryTree } from '@/types';

export const useIndustryTree = (activeOnly: boolean = true) => {
  const [tree, setTree] = useState<IndustryNode[]>([]);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);

  const fetchTree = async () => {
    setLoading(true);
    try {
      const data = await api.get('/industry-tree', { params: { active_only: activeOnly } });
      setTree(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  const generateChildren = async (parentId: string, count: number = 5) => {
    const res = await api.post(`/industry-tree/${parentId}/generate`, { count });
    await fetchTree(); // 刷新树
    return res;
  };

  const getPath = async (nodeId: string) => {
    return await api.get(`/industry-tree/${nodeId}/path`);
  };

  // 供其他模块调用的方法
  const matchIndustry = async (text: string) => {
    return await api.post('/industry-tree/match', { text });
  };

  useEffect(() => {
    fetchTree();
  }, [activeOnly]);

  return { tree, loading, error, fetchTree, generateChildren, getPath, matchIndustry };
};
```

### 8.2 知识库条目关联行业

知识库表中的 `industry_tree_id` 字段关联到行业树节点，实现“知识库条目 → 行业分类”的双向索引。

### 8.3 评分点自动预填充

新建项目时，根据选定的行业节点，读取 `default_scoring_items` 字段，自动生成初始评分点列表（用户可二次编辑）。

### 8.4 文件解析自动识别

调用 `match_industry` API，在文件解析阶段自动识别项目所属行业，减少用户手动选择步骤。
