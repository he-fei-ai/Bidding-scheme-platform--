# 甘特图生成提示词（优化版 v2.0）

## 优化说明

| 优化点 | 原版问题 | 改进措施 |
|--------|----------|----------|
| 角色定位模糊 | 描述过于简单 | 聚焦"任务拆解+依赖关系编排+工程语境对齐"核心能力 |
| 任务数量无约束 | 可能产生过多或过少任务 | 严格控制5~7个，确保Word表格中一页内完整展示 |
| 日期格式不合理 | 使用绝对日期（YYYY-MM-DD）导致穿帮 | 使用虚拟起始日2024-01-01 + after id 相对工期 |
| 依赖关系描述泛化 | 仅一笔带过 | 明确FS默认规则，支持合理搭接，提供示例 |
| 缺少工程语境 | 任务名称可能空洞 | 强制任务名称与项目实际施工内容对齐 |
| 缺少避坑指南 | 常见错误未提前阻断 | 增加日期穿帮、串并行混淆、里程碑误用等典型错误示例 |
| 轴标签不友好 | 使用%m-%d英文格式 | 改为%m月%d日中文标注 |

## Mermaid 甘特图输出规范

### 基本结构

```
gantt
    title 甘特图标题
    dateFormat YYYY-MM-DD
    axisFormat %m月%d日

    section 分组名1
    任务名1 :id1, 2024-01-01, 15d
    任务名2 :id2, after id1, 10d

    section 分组名2
    任务名3 :id3, after id2, 25d
    里程碑  :milestone, id4, after id3, 0d
```

### 语法规则

1. **gantt**：必须以gantt关键字开头
2. **title**：专业的甘特图标题，包含项目类型和内容
3. **dateFormat**：固定为 `YYYY-MM-DD`
4. **axisFormat**：固定为 `%m月%d日`（中文月份标注）
5. **section**：按工程阶段分组（施工准备、主体施工、收尾验收等）
6. **任务行格式**：
   - 普通任务：`任务名 : id, 起始日期, 持续时间Nd`
   - 依赖任务：`任务名 : id, after 前置id, 持续时间Nd`
   - 里程碑：`节点名 : milestone, id, after 前置id, 0d`
7. **id命名**：使用简短字母+数字（如a1, a2, t1），唯一不重复
8. **起始日期**：第一个任务固定使用 `2024-01-01`（虚拟起始日）
9. **持续时间**：整数+d（如15d、30d），每项≥3d
10. **纯净返回**：直接返回Mermaid代码，无代码块包裹，无解释文字

### 任务拆解约束

- 任务数量：**5~7个**（不含里程碑）
- 粒度：**主要工序级**，禁止拆成每日微观作业
- 命名：体现**具体工程内容**（如"外墙旧饰面铲除"而非"阶段一"），≤20汉字
- 依赖：默认FS（完成-开始），用 `after id` 表达；可合理搭接
- 总工期：所有任务工期之和应接近项目总工期
- 里程碑：最后设置"竣工验收"里程碑（duration=0d）

### 输入参数

| 参数 | 说明 |
|------|------|
| section_title | 章节标题 |
| section_content | 章节正文内容（含施工方法描述） |
| summary | 项目概述（含总工期、工程规模、实施内容） |
| scoring_standard | 评分标准（进度计划相关得分点） |
| industry_profile | 行业背景信息 |

### 避坑指南

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| **日期穿帮** | 使用2025-03-15等真实日期 | 一律用2024-01-01作为虚拟起始日 |
| **任务命名空洞** | "阶段一"、"前期准备" | 写具体工序名如"施工图深化设计" |
| **串并行混淆** | 屋面防水与外墙施工强制串行 | 可并行任务独立设置起始点 |
| **任务过细** | "绑扎钢筋第1天" | 保持5-7个主要工序级任务 |
| **依赖循环** | a依赖b，b依赖a | 检查依赖关系无环 |
| **总工期溢出** | 任务结束日期超过总工期 | 所有任务在总工期内完成 |
| **遗漏里程碑** | 没有竣工验收节点 | 最后设置竣工验收里程碑 |
| **使用status标签** | 任务名后加:active、:done、:crit | 不使用status标签，避免兼容性问题 |

### 标准示例（外墙整修项目，总工期120天）

```
gantt
    title 外墙整修工程施工进度计划
    dateFormat YYYY-MM-DD
    axisFormat %m月%d日

    section 施工准备
    施工图深化设计及送审 :a1, 2024-01-01, 15d
    外脚手架搭设及防护   :a2, after a1, 10d

    section 主体施工
    外墙旧饰面铲除清理   :a3, after a2, 25d
    外墙基层找平及防水   :a4, after a3, 20d
    外墙保温一体板安装   :a5, after a4, 25d
    门窗及金属构件翻新   :a6, after a5, 20d

    section 收尾验收
    脚手架拆除及场地清理 :a7, after a6, 10d
    竣工验收及移交       :milestone, a8, after a7, 0d
```
