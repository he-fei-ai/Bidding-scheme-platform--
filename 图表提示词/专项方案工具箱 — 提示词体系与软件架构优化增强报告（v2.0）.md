## 二、核心优化与增强方案（v2.0 整合版）

### 2.1 已完成：六类图表编排+生成提示词全面优化

基于《AI自主图表编排与多模态内容生成系统规范 v3.0》，六类图表的编排与生成提示词已完成优化对齐：

| 图表类型     | 编排提示词核心输出                                           | 生成提示词核心输出                                           | 互斥优先级 |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ---------- |
| **甘特图**   | `{ needed, type, priority, reason, phaseCountHint, estimatedPeak, taskDependencyHint }` | `GanttPlan` JSON（5~7任务，含start/end/dependencies/isMilestone） | 5（最高）  |
| **架构图**   | `{ needed, type, priority, reason, nodeCountHint, depthHint }` | `ArchNode` JSON（≤15节点，≤3层，ID ASCII）                   | 4          |
| **流程图**   | `{ needed, type, priority, reason, nodeCountHint, flowHint }` | 纯净Mermaid代码（3~10节点，无围栏，无双引号缺失）            | 4          |
| **劳动力图** | `{ needed, type, priority, reason, phaseCountHint, estimatedPeak }` | `LaborPlan` JSON（3~6阶段×3~6工种，维度一致）                | 3          |
| **布局图**   | `{ needed, type, priority, reason, nodeCountHint }`          | Mermaid代码（subgraph分区）                                  | 2          |
| **对比图**   | `{ needed, type, priority, reason, dataCountHint }`          | Mermaid Pie / xychart-beta                                   | 2          |

### 2.2 已完成：内联数据图表模块集成

`AI自主图表编排规范v3.0` 已纳入内联图表（柱状图/饼图/折线图）的触发与生成规范：

- **触发条件**：章节中出现 5 组及以上并列数据，或需要展示阶段趋势变化
- **输出格式**：`<!-- AI_Chart_Start --> [CHART_TYPE: 柱状图/饼图/折线图] [CHART_DATA: {...}] <!-- AI_Chart_End -->`
- **渲染路径**：`shared/inlineChartParser.ts` → 前端 Chart.js / ECharts → SVG/PNG → DOCX 嵌入

### 2.3 已完成：AI插图编排层的成本拦截与风格锚定

优化后的 `imageArrange` 编排提示词已内置成本控制逻辑：

```text
【成本拦截规则】
在判断 needed 前，隐式检查系统内置变量 {is_image_enabled} 与 {max_images_per_project}。
若图片生成功能已关闭或已达项目上限，必须将 needed 置为 false，
并在 reason 中输出“因全局配置限制，本章跳过 AI 插图生成”。
```

优化后的 `imageGenerate` 生成提示词已强制风格锚定：

```text
【风格锚定规则】
将 image_model_configs 表中的全局 style_preset 值，
作为英文 Prompt 的前缀注入：
"Photorealistic architectural photography, {style_preset} ..."
确保全书 AI 生图风格与配置面板严格一致。
```

### 2.4 已完成：正文生成阶段的“防幻觉与防重叠”约束

`generateChapter` 提示词已新增叙事边界约束：

```text
【叙事边界规则】
请严格区分本级章节与上级父级章节的叙事边界。
严禁在当前章节中，引入应在上一级章节中介绍的项目背景、工程概况或宏观政策描述。
内容应紧贴当前树形路径（{parent_title} → {current_title}），
聚焦于本节的特定工艺、方法或具体管理措施。
```

### 2.5 已完成：图表生成兜底修复机制（`chartDataFix`）

通用图表兜底提示词 `chartDataFix` 已设计完成：

- **调用时机**：任意图表模块生成失败，或渲染器返回错误时
- **修复策略**：
  1. 分析错误原因（参考 `error_message`）
  2. 基于有效上下文重新输出符合 `shared/types.ts` 定义的 JSON 数据
  3. **强制简化**：若原数据过于复杂，将任务数/节点数压缩至下限（甘特图保留3个核心任务，架构图保留2级核心节点）
  4. 优先保证文档中图表存在且能稳定渲染

### 2.6 待实现：版本对比与回滚决策提示词（`versionCompare`）

> **状态**：已规划，待开发实现

- **调用服务**：`VersionService.compare()`
- **输入**：两个版本的完整章节目录树与正文内容
- **输出**：按【新增章节】、【删除章节】、【修改正文内容】三类结构化对比结论
- **语言要求**：客观中立，仅陈述变动事实，不进行倾向性评价
