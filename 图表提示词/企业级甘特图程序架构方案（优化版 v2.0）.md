企业级甘特图程序架构方案（优化版 v2.0）

## 优化说明

| 优化点                    | 原版问题                                                 | 改进措施                                                     |
| ------------------------- | -------------------------------------------------------- | ------------------------------------------------------------ |
| **定位不清晰**            | 前半部分是可运行的HTML代码，后半部分是集成建议，结构混杂 | 重组为“数据模型→前端渲染器→多端集成→平台集成路径”四层结构    |
| **与平台数据模型脱节**    | 未说明如何与平台的 `gantt_json` 字段对接                 | 新增“数据模型定义”章节，明确与 `GanttTask` / `GanttPlan` 接口的映射关系 |
| **依赖关系仅文字描述**    | 提及“增强方向”但无具体实现                               | 在数据模型中增加 `dependencies`、`isMilestone` 字段，并更新渲染器支持 |
| **与Mermaid渲染关系不明** | 未说明与平台现有Mermaid甘特图的协作关系                  | 新增“与Mermaid渲染的协作关系”说明                            |
| **与DOCX导出脱节**        | 未说明如何将甘特图嵌入Word文档                           | 新增“DOCX导出集成”说明                                       |
| **代码可复用性不足**      | 渲染器与业务数据耦合                                     | 重构为纯引擎类 + 独立业务数据注入                            |
| **缺少真实日期计算**      | 仅有相对天数，无日历映射                                 | 新增 `Dayjs` 适配器，支持相对天数→真实日期转换               |


## 一、概述

### 1.1 模块定位

甘特图模块是平台 **配图引擎** 的核心组成部分，与流程图（Mermaid）、架构图（Architecture）、劳动力图（Labor）并列。其职责是：

1. **编排阶段**：根据章节内容判断是否需要生成甘特图，并输出任务骨架（`tasks` + `totalDays`）——参见《甘特图编排提示词》
2. **生成阶段**：将编排输出的任务骨架补全为完整的甘特图数据（含 `start`/`end`/`dependencies`/`isMilestone`）——参见《甘特图生成提示词》
3. **渲染阶段**：将甘特图数据渲染为可视化图表（前端预览或DOCX导出）

### 1.2 渲染形态

| 渲染形态          | 适用场景             | 实现方式                     |
| ----------------- | -------------------- | ---------------------------- |
| **原生HTML表格**  | 前端预览、页面展示   | 本方案提供的 `GanttEngine`   |
| **Mermaid甘特图** | 导出DOCX时的图片渲染 | 平台现有 Mermaid 渲染管线    |
| **原生Word表格**  | DOCX导出（备选方案） | `python-docx` 构建表格       |
| **PNG图片**       | DOCX导出（主方案）   | 前端渲染后截图 / Mermaid渲染 |


## 二、数据模型定义

### 2.1 统一数据接口 Schema（`GanttPlan`）

本模块采用与平台 `gantt_json` 字段完全一致的数据结构：

```typescript
// 甘特图任务节点
interface GanttTask {
  id: number;                    // 任务序号（从1开始递增）
  name: string;                  // 任务名称（≤20字符）
  start: number;                 // 相对工期起始天数（第1天=1）
  end: number;                   // 相对工期结束天数（≥ start）
  dependencies: number[];        // 前置任务ID列表（如 [1, 2] 表示依赖任务1和2）
  isMilestone: boolean;          // 是否为里程碑节点（start === end）
}

// 甘特图完整计划
interface GanttPlan {
  needed: boolean;               // 是否需要生成
  totalDays: number;             // 总工期天数
  tasks: GanttTask[];           // 任务列表（5～7个）
  priority: number;             // 优先级 3/4/5
  reason: string;               // 判断依据（≤80字）
}
```

### 2.2 与平台字段映射

| 数据库字段                   | 数据模型    | 说明                                      |
| ---------------------------- | ----------- | ----------------------------------------- |
| `sections.gantt_json`        | `GanttPlan` | 章节关联的甘特图数据（编排+生成阶段产出） |
| `sections.illustration_type` | `"gantt"`   | 当该章节最终配图类型为甘特图时标记        |

### 2.3 真实日期映射（扩展能力）

支持通过 `startDate` 参数将相对天数映射为真实日历日期（可选，供导出场景使用）：

```typescript
interface GanttPlanWithDate extends GanttPlan {
  startDate: string;             // 项目起始日期（如 "2026-06-27"）
  endDate: string;               // 项目结束日期（由 totalDays 推算）
  tasksWithDate: {
    id: number;
    name: string;
    startDate: string;           // 起始日期
    endDate: string;             // 结束日期
    dependencies: number[];
    isMilestone: boolean;
  }[];
}
```


## 三、前端渲染引擎（`GanttEngine`）

### 3.1 核心设计原则

- **数据驱动**：传入 `GanttPlan` 数据，自动计算时间轴跨度与进度条位置
- **无外部依赖**：纯原生 JavaScript + CSS，可直接嵌入任何前端项目
- **自适应可视化**：自动计算网格刻度、任务条位置与宽度
- **交互能力**：支持任务条悬浮提示（Tooltip），显示任务详情
- **可扩展**：支持依赖关系线绘制（`dependencies`）和里程碑节点渲染

```html
<script>
/**
 * ================================================================
 *  GanttEngine — 原生 JS 甘特图渲染引擎（平台集成版）
 *  支持：数据驱动渲染 / 依赖关系连线 / 里程碑节点 / 悬浮提示
 * ================================================================
 */
class GanttEngine {
    /**
     * @param {string|HTMLElement} container - DOM 容器 ID 或元素
     * @param {Object} plan - GanttPlan 数据
     * @param {Object} options - 可选配置
     */
    constructor(container, plan, options = {}) {
        this.container = typeof container === 'string'
            ? document.getElementById(container)
            : container;
        this.plan = plan;
        this.options = Object.assign({
            showDependencies: true,
            barHeight: 28,
            barTopOffset: 6,
            gridTickInterval: 10,
            colors: {
                standard: 'linear-gradient(90deg, #2b74e8, #4a8cf7)',
                milestone: 'linear-gradient(90deg, #e85a2b, #f77a4a)'
            }
        }, options);

        if (!this.container) {
            console.error('GanttEngine: 容器不存在');
            return;
        }

        this._tooltip = null;
        this.init();
    }

    // ---------- 初始化 ----------
    init() {
        this._createTooltip();
        this.render();
    }

    // ---------- 更新数据 ----------
    setPlan(newPlan) {
        this.plan = newPlan;
        this.render();
    }

    // ---------- 核心渲染 ----------
    render() {
        if (!this.plan || !this.plan.tasks || this.plan.tasks.length === 0) {
            this.container.innerHTML = '<div style="padding: 40px; text-align: center; color: #8892a0;">暂无甘特图数据</div>';
            return;
        }

        const { tasks, totalDays } = this.plan;
        const maxDays = totalDays || this._calcMaxDays(tasks);

        // 更新总工期显示
        const displayEl = document.getElementById('totalDaysDisplay');
        if (displayEl) displayEl.textContent = maxDays;

        // 构建表格
        const table = document.createElement('table');
        table.className = 'gantt-table';

        // ---- 表头 ----
        const thead = document.createElement('thead');
        thead.innerHTML = `
            <tr>
                <th class="col-id">#</th>
                <th class="col-name">任务名称</th>
                <th class="col-date">开始</th>
                <th class="col-date">完成</th>
                <th class="col-duration">工期</th>
                <th style="min-width: 300px;">施工时间轴（${maxDays}天）</th>
            </tr>
        `;
        table.appendChild(thead);

        // ---- 表体 ----
        const tbody = document.createElement('tbody');
        const taskMap = {};

        tasks.forEach((task, index) => {
            const tr = document.createElement('tr');
            const duration = task.end - task.start + 1;
            const leftPct = ((task.start - 1) / maxDays) * 100;
            const widthPct = (duration / maxDays) * 100;

            const isMilestone = task.isMilestone || (task.start === task.end);
            const barClass = isMilestone ? 'task-bar milestone' : 'task-bar standard';
            const barStyle = `left: ${Math.max(leftPct, 0)}%; width: ${Math.max(widthPct, 2)}%;`;

            // 任务条内容（非里程碑显示起止天数）
            const barLabel = isMilestone ? '◆' : `${task.start}-${task.end}`;

            // 构建网格刻度
            const tickCount = Math.ceil(maxDays / this.options.gridTickInterval);
            let gridHtml = '<div class="grid-lines">';
            for (let i = 0; i <= tickCount; i++) {
                let label = i * this.options.gridTickInterval;
                if (label > maxDays) label = maxDays;
                gridHtml += `<div class="grid-tick">${label}</div>`;
            }
            gridHtml += '</div>';

            // 构建依赖关系连线 SVG（仅里程碑或标准任务）
            let depsSvg = '';
            if (this.options.showDependencies && task.dependencies && task.dependencies.length > 0) {
                // 在任务渲染后绘制连线，此处留占位
                depsSvg = `<svg class="dependencies-overlay" id="deps-${task.id}"></svg>`;
            }

            tr.innerHTML = `
                <td class="col-id">${task.id}</td>
                <td class="col-name">${this._escapeHtml(task.name)}</td>
                <td class="col-date">${task.start}</td>
                <td class="col-date">${task.end}</td>
                <td class="col-duration">${duration}天</td>
                <td class="col-chart" data-task-id="${task.id}">
                    ${gridHtml}
                    <div class="${barClass}" style="${barStyle}" data-task-id="${task.id}">
                        <span class="bar-label">${barLabel}</span>
                    </div>
                    ${depsSvg}
                </td>
            `;

            tbody.appendChild(tr);
            taskMap[task.id] = { task, row: tr, element: tr.querySelector('.col-chart') };
        });

        table.appendChild(tbody);
        this.container.innerHTML = '';
        this.container.appendChild(table);

        // ---- 绑定 Tooltip 事件 ----
        this._bindTooltips();

        // ---- 绘制依赖关系连线（延时确保 DOM 布局完成） ----
        if (this.options.showDependencies) {
            requestAnimationFrame(() => {
                this._drawDependencies(taskMap, maxDays);
            });
        }
    }

    // ---------- 计算最大天数 ----------
    _calcMaxDays(tasks) {
        let maxEnd = 0;
        tasks.forEach(t => { if (t.end > maxEnd) maxEnd = t.end; });
        return maxEnd || 100;
    }

    // ---------- 创建 Tooltip 元素 ----------
    _createTooltip() {
        if (!this._tooltip) {
            this._tooltip = document.createElement('div');
            this._tooltip.className = 'gantt-tooltip';
            document.body.appendChild(this._tooltip);
        }
    }

    // ---------- 绑定悬浮提示 ----------
    _bindTooltips() {
        const bars = this.container.querySelectorAll('.task-bar');
        bars.forEach(bar => {
            bar.addEventListener('mouseenter', (e) => {
                const taskId = parseInt(bar.dataset.taskId);
                const task = this.plan.tasks.find(t => t.id === taskId);
                if (!task) return;

                const dur = task.end - task.start + 1;
                const deps = task.dependencies && task.dependencies.length > 0
                    ? `依赖: ${task.dependencies.join(', ')}`
                    : '无依赖';

                this._tooltip.innerHTML = `
                    <div class="tt-title">${this._escapeHtml(task.name)}</div>
                    <div class="tt-detail">工期: ${dur}天 (第${task.start}天 ~ 第${task.end}天)</div>
                    <div class="tt-detail">${deps}</div>
                    ${task.isMilestone ? '<div class="tt-detail">🔹 里程碑节点</div>' : ''}
                `;
                this._tooltip.style.display = 'block';
                this._tooltip.style.left = (e.clientX + 12) + 'px';
                this._tooltip.style.top = (e.clientY - 10) + 'px';
            });

            bar.addEventListener('mouseleave', () => {
                this._tooltip.style.display = 'none';
            });

            bar.addEventListener('mousemove', (e) => {
                this._tooltip.style.left = (e.clientX + 12) + 'px';
                this._tooltip.style.top = (e.clientY - 10) + 'px';
            });
        });
    }

    // ---------- 绘制依赖关系连线 ----------
    _drawDependencies(taskMap, maxDays) {
        const plan = this.plan;
        plan.tasks.forEach(task => {
            if (!task.dependencies || task.dependencies.length === 0) return;

            const depIds = task.dependencies;
            const targetEl = taskMap[task.id]?.element;
            if (!targetEl) return;

            const targetRect = targetEl.getBoundingClientRect();
            const containerRect = this.container.getBoundingClientRect();

            // 获取每个依赖任务的结束位置
            depIds.forEach(depId => {
                const depTask = plan.tasks.find(t => t.id === depId);
                if (!depTask) return;

                const depEl = taskMap[depId]?.element;
                if (!depEl) return;

                const depRect = depEl.getBoundingClientRect();
                const startX = depRect.right - containerRect.left;
                const endX = targetRect.left - containerRect.left;
                const y = (depRect.top + depRect.bottom) / 2 - containerRect.top;

                // 创建 SVG 连线
                const svg = targetEl.querySelector(`#deps-${task.id}`);
                if (svg) {
                    const path = document.createElementNS('http://www.w3.org/2000/svg', 'path');
                    const d = `M ${startX} ${y} L ${endX - 8} ${y}`;
                    path.setAttribute('d', d);
                    path.setAttribute('stroke', '#b0b8c4');
                    path.setAttribute('stroke-width', '1.5');
                    path.setAttribute('fill', 'none');
                    // 箭头标记
                    path.setAttribute('marker-end', 'url(#arrowhead)');
                    svg.appendChild(path);

                    // 添加箭头定义
                    if (!svg.querySelector('defs')) {
                        const defs = document.createElementNS('http://www.w3.org/2000/svg', 'defs');
                        const marker = document.createElementNS('http://www.w3.org/2000/svg', 'marker');
                        marker.setAttribute('id', 'arrowhead');
                        marker.setAttribute('markerWidth', '8');
                        marker.setAttribute('markerHeight', '8');
                        marker.setAttribute('refX', '6');
                        marker.setAttribute('refY', '4');
                        const poly = document.createElementNS('http://www.w3.org/2000/svg', 'polygon');
                        poly.setAttribute('points', '0 0, 8 4, 0 8');
                        poly.setAttribute('fill', '#b0b8c4');
                        marker.appendChild(poly);
                        defs.appendChild(marker);
                        svg.appendChild(defs);
                    }
                }
            });
        });
    }

    // ---------- 工具：HTML 转义 ----------
    _escapeHtml(text) {
        const div = document.createElement('div');
        div.textContent = text;
        return div.innerHTML;
    }

    // ---------- 获取当前数据 ----------
    getData() {
        return this.plan;
    }
}
```

### 4.1 React 集成

```tsx
// GanttChart.tsx
import React, { useEffect, useRef, useState } from 'react';

interface GanttTask {
  id: number;
  name: string;
  start: number;
  end: number;
  dependencies: number[];
  isMilestone: boolean;
}

interface GanttPlan {
  needed: boolean;
  totalDays: number;
  tasks: GanttTask[];
  priority: number;
  reason: string;
}

interface GanttChartProps {
  plan: GanttPlan;
  className?: string;
  showDependencies?: boolean;
}

export const GanttChart: React.FC<GanttChartProps> = ({
  plan,
  className = '',
  showDependencies = true,
}) => {
  const containerRef = useRef<HTMLDivElement>(null);
  const engineRef = useRef<any>(null);
  const [isReady, setIsReady] = useState(false);

  useEffect(() => {
    // 动态加载 GanttEngine（假设已通过 CDN 或模块导入）
    const loadEngine = async () => {
      if (!containerRef.current) return;
      // 生产环境：从 npm 包或 CDN 导入
      const { GanttEngine } = await import('@/lib/GanttEngine');
      engineRef.current = new GanttEngine(containerRef.current, plan, {
        showDependencies,
      });
      setIsReady(true);
    };
    loadEngine();

    return () => {
      if (engineRef.current) {
        // 清理资源
        engineRef.current.container.innerHTML = '';
      }
    };
  }, []);

  // 数据变更时更新
  useEffect(() => {
    if (engineRef.current && isReady) {
      engineRef.current.setPlan(plan);
    }
  }, [plan, isReady]);

  return <div ref={containerRef} className={`gantt-wrapper ${className}`} />;
};
```

### 4.3 Web Component 封装（零框架通用）

```javascript
// gantt-component.js
class GanttChartElement extends HTMLElement {
  static get observedAttributes() { return ['data']; }

  connectedCallback() {
    this._container = document.createElement('div');
    this.appendChild(this._container);
    this._engine = null;
    this._render();
  }

  attributeChangedCallback(name, oldValue, newValue) {
    if (name === 'data' && newValue) {
      try {
        const plan = JSON.parse(newValue);
        this._plan = plan;
        this._render();
      } catch (e) {
        console.error('GanttChart: 无效的 JSON 数据', e);
      }
    }
  }

  set data(value) {
    this.setAttribute('data', typeof value === 'string' ? value : JSON.stringify(value));
  }

  _render() {
    if (!this._container || !this._plan) return;
    if (this._engine) {
      this._engine.setPlan(this._plan);
    } else {
      // 动态导入 GanttEngine
      import('@/lib/GanttEngine').then(({ GanttEngine }) => {
        this._engine = new GanttEngine(this._container, this._plan);
      });
    }
  }
}

customElements.define('gantt-chart', GanttChartElement);
```

### 5.2 与 Mermaid 渲染的协作

平台现有 Mermaid 渲染管线同样支持甘特图（`gantt` 语法），与 `GanttEngine` 的关系如下：

| 维度         | GanttEngine（本方案）  | Mermaid 甘特图                |
| ------------ | ---------------------- | ----------------------------- |
| **渲染形态** | HTML 表格 + CSS 进度条 | SVG 图表                      |
| **适用场景** | 前端预览、交互展示     | DOCX 导出、PDF 报告           |
| **数据格式** | `GanttPlan` JSON       | `gantt` 语法字符串            |
| **交互能力** | 悬浮提示、动态更新     | 静态图片                      |
| **依赖关系** | 支持连线绘制           | 支持（通过 `after` 语法）     |
| **里程碑**   | 支持（菱形标识）       | 支持（通过 `milestone` 语法） |

**推荐策略**：
1. **前端预览**：使用 `GanttEngine` 渲染，提供更好的交互体验
2. **DOCX 导出**：使用 Mermaid 渲染（由 `gantt_json` 转换为 `gantt` 语法 → 转 PNG → 插入 Word），保持与平台现有配图管线一致

### 5.3 数据转换：GanttPlan → Mermaid 甘特图语法

```javascript
function ganttPlanToMermaid(plan) {
  const { tasks, totalDays, title } = plan;
  let lines = [
    'gantt',
    `    title ${title || '施工进度计划'}`,
    '    dateFormat  X',
    '    axisFormat %d',
    `    tickInterval ${Math.ceil(totalDays / 10)}day`
  ];

  tasks.forEach(task => {
    const dur = task.end - task.start + 1;
    const deps = (task.dependencies || [])
      .map(id => `after task_${id}`)
      .join(', ');
    const milestoneSuffix = task.isMilestone ? ', milestone' : '';
    lines.push(
      `    ${task.isMilestone ? 'milestone' : 'section'} ${task.name} :${deps} task_${task.id}, ${task.start}, ${dur}${milestoneSuffix}`
    );
  });

  return lines.join('\n');
}
```

   - 读取 `gantt_json`
   - 转换为 Mermaid 甘特图语法
   - 调用 Mermaid 渲染器转 PNG
   - 插入 Word 文档
