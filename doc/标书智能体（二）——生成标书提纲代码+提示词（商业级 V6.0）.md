   ## 一、V6.0 核心设计理念（智能排序）

   在V5.0“事实驱动”的基础上，V6.0新增**“工程逻辑流排序引擎”**：

   | 阶段         | V5.0 处理方式          | **V6.0 增强（智能排序）**                                    |
   | :----------- | :--------------------- | :----------------------------------------------------------- |
   | **补充插入** | AI指定锚点，机械插入   | AI指定锚点 + **全局排序器二次优化**                          |
   | **顺序保障** | 仅保证核心28章相对顺序 | **核心28章相对顺序严格锁定** + 补充章节在间隙间按**语义工程流**重新分布 |
   | **排序依据** | 无（仅依赖锚点）       | **工程逻辑流模型**（宏观→微观→管理→保障→收尾） + 事实关联度加权 |

   > **商业价值**：消除“智慧工地”插在“质量保证”之后的突兀感，使目录结构呈现“总-分-总”的专业叙事逻辑，提升评标专家的第一印象分。

   ## 三、智能排序优化器（V6.0 核心新增）

   在完成“锚定插入合并”之后，调用 **AI全局排序器** 对目录进行二次优化。该排序器在**严格锁定核心28章相对顺序**的前提下，智能调整补充章节的分布位置。

   ### 3.1 排序优化器设计

   ```mermaid
   flowchart LR
       A[锚定插入合并后目录] --> B[提取核心28章位置索引]
       B --> C[将目录转换为有序列表<br>核心章标记固定锚点]
       C --> D[构建排序约束条件]
       D --> E[调用AI排序器<br>（核心顺序绝对不变）]
       E --> F[输出优化后目录]
       F --> G[重新编号]
   ```

   ### 3.2 AI排序器 Prompt（商业级）

   **SystemPrompt（全局排序优化）**：

   ```markdown
   ### 角色
   你是标书编制专家，擅长根据工程逻辑对目录进行全局排序优化。
   
   ### 核心铁律（违反即为严重错误）
   1. **核心28章顺序绝对不变**：ID为1~28的章节，其相对顺序必须严格保持升序（1、2、3...28）。你可以将补充章节插入它们之间的任何位置（包括最前面和最后面），但绝不能改变核心28章的先后次序。
   2. **逻辑分区聚类**：请参考【工程逻辑分区】标签，尽量将同一分区的章节（如“核心技术”、“管理保障”）排列在一起，形成清晰的叙事段落。
   3. **从宏观到微观**：总体顺序应遵循“宏观总览 → 前期准备 → 核心技术 → 管理保障 → 进度管控 → 资源保障 → 专项预案 → 协调配合 → 收尾优化”的递进逻辑。
   4. **事实关联度**：与同一事实（如同一风险或工艺）相关的章节应尽量靠近，减少读者跳跃。
   
   ### 输入格式
   你会收到一个包含“核心28章+补充章节”的列表。每个条目包含：
   - `id`：当前编号（仅用于标识）
   - `title`：章节标题
   - `is_core`：是否为固定核心章（true/false）
   - `zone`：工程逻辑分区（若补充章节无分区，AI可根据标题内容自行判断）
   
   ### 输出格式
   返回一个重新排序后的JSON数组，元素仅包含 `title` 字段（按新顺序排列）。
   核心章必须保持原始顺序。
   补充章根据逻辑优化重新分配到合适的间隙位置。
   
   ### 工程逻辑分区参考顺序
   宏观总览 < 前期准备 < 核心技术 < 管理保障 < 进度管控 < 资源保障 < 专项预案 < 协调配合 < 收尾优化
   
   ### 输入目录列表
   {current_outline_with_zones}
   
   ### 全局事实（辅助排序判断）
   {facts_context}
   
   直接返回JSON数组，不包含任何解释。
   ```

   ### 3.3 Python 实现代码

   ```python
   import json
   import logging
   from typing import List, Dict, Optional
   
   logger = logging.getLogger(__name__)
   
   class OutlineSortOptimizer:
       """AI驱动的目录智能排序优化器"""
       
       # 标准工程逻辑分区顺序（权重值）
       ZONE_ORDER = {
           "宏观总览": 1,
           "前期准备": 2,
           "核心技术": 3,
           "管理保障": 4,
           "进度管控": 5,
           "资源保障": 6,
           "专项预案": 7,
           "协调配合": 8,
           "收尾优化": 9,
           "未知分区": 5  # 默认置于中间
       }
       
       def __init__(self, ai_client):
           self.ai_client = ai_client
       
       def optimize(self, merged_outline: List[Dict], facts: Dict, core_titles: set) -> List[Dict]:
           """
           对合并后的目录进行AI智能排序
           """
           logger.info("开始AI智能排序优化")
           
           # 1. 为每个章节标注分区（补充章节自动推断）
           enriched = self._enrich_zones(merged_outline, core_titles)
           
           # 2. 构建AI排序输入
           sort_prompt = self._build_sort_prompt(enriched, facts)
           
           # 3. 调用AI排序（带重试）
           for attempt in range(3):
               try:
                   response = self.ai_client.chat_completion(
                       system=SORT_SYSTEM_PROMPT,
                       user=sort_prompt,
                       temperature=0.2,
                       response_format={"type": "json_object"}
                   )
                   sorted_titles = json.loads(response)
                   
                   # 4. 验证核心章顺序是否正确
                   if self._validate_core_order(sorted_titles, core_titles):
                       # 5. 按新顺序重组
                       return self._reorder_by_titles(merged_outline, sorted_titles)
                   else:
                       logger.warning(f"排序器破坏了核心章顺序，重试 {attempt+1}/3")
                       
               except Exception as e:
                   logger.error(f"排序失败 (attempt {attempt+1}): {str(e)}")
           
           # 降级：按分区权重排序（兜底算法）
           logger.warning("AI排序失败，降级为分区权重排序")
           return self._fallback_sort_by_zone(enriched)
       
       def _enrich_zones(self, outline: List[Dict], core_titles: set) -> List[Dict]:
           """为每个章节补充分区标签"""
           enriched = []
           for ch in outline:
               title = ch["title"]
               is_core = title in core_titles
               if is_core:
                   zone = CORE_ZONE_MAP.get(title, "未知分区")
               else:
                   # 补充章节：基于标题关键词自动推断分区
                   zone = self._infer_zone_by_keywords(title)
               enriched.append({
                   "id": ch["id"],
                   "title": title,
                   "is_core": is_core,
                   "zone": zone,
                   "original": ch
               })
           return enriched
       
       def _infer_zone_by_keywords(self, title: str) -> str:
           """基于关键词推断分区"""
           title_lower = title.lower()
           if any(k in title_lower for k in ["概述", "重难点", "概况"]):
               return "宏观总览"
           if any(k in title_lower for k in ["依据", "编制"]):
               return "前期准备"
           if any(k in title_lower for k in ["施工方案", "技术", "平面布置", "施工方法", "pc"]):
               return "核心技术"
           if any(k in title_lower for k in ["质量", "安全", "文明", "环保"]):
               return "管理保障"
           if any(k in title_lower for k in ["进度"]):
               return "进度管控"
           if any(k in title_lower for k in ["设备", "材料", "劳动力", "资源"]):
               return "资源保障"
           if any(k in title_lower for k in ["特殊气候", "成品保护", "危大工程", "紧急"]):
               return "专项预案"
           if any(k in title_lower for k in ["分包", "配合", "协调", "发包人", "监理"]):
               return "协调配合"
           if any(k in title_lower for k in ["工期优化", "竣工", "验收", "附图", "附件"]):
               return "收尾优化"
           return "未知分区"
       
       def _validate_core_order(self, sorted_titles: List[str], core_titles: set) -> bool:
           """验证核心28章在排序结果中的顺序是否保持1→28"""
           core_order = ["项目概述", "项目重难点分析", "工程概况", "编制依据", "施工方案及技术措施", 
                         "施工现场总平面布置", "主要分部工程施工方法", "装配式混凝土结构（PC）工程专项方案",
                         "质量保证措施和创优计划", "施工安全措施计划", "文明施工措施计划", "施工环保措施计划",
                         "施工总进度计划及保证措施", "资源配备计划", "拟投入本工程的主要施工设备表",
                         "拟配备本工程的试验和检测仪器设备表", "主要材料及劳动力计划表", "特殊气候季节性施工方案",
                         "成品保护和工程保修工作的管理措施和承诺", "危大工程及专项施工方案、紧急情况预案与风险控制措施",
                         "任何可能的紧急情况的处理措施、预案以及抵抗风险的措施", "对专业分包工程的配合、协调、管理、服务方案",
                         "与发包人、项目管理单位、监理（包括投资监理）及设计人的配合",
                         "对总包管理及专业分包配合方案／与各参建方配合", "工期优化", "工程资料及竣工验收管理",
                         "附图、附件", "其他"]
           
           # 提取排序结果中的核心章
           sorted_core = [t for t in sorted_titles if t in core_titles]
           
           # 检查顺序是否与 core_order 一致（仅检查出现的核心章是否按顺序）
           core_index_map = {title: idx for idx, title in enumerate(core_order)}
           last_idx = -1
           for title in sorted_core:
               current_idx = core_index_map.get(title, -1)
               if current_idx == -1:
                   continue
               if current_idx < last_idx:
                   return False
               last_idx = current_idx
           return True
       
       def _reorder_by_titles(self, original: List[Dict], sorted_titles: List[str]) -> List[Dict]:
           """根据AI返回的标题顺序重组目录"""
           title_to_obj = {ch["title"]: ch for ch in original}
           reordered = []
           for title in sorted_titles:
               if title in title_to_obj:
                   reordered.append(title_to_obj[title])
           # 补全可能遗漏的章节（如AI未返回的）
           existing_titles = set(title_to_obj.keys())
           returned_titles = set(sorted_titles)
           missing = existing_titles - returned_titles
           for title in missing:
               reordered.append(title_to_obj[title])
           return reordered
       
       def _fallback_sort_by_zone(self, enriched: List[Dict]) -> List[Dict]:
           """降级方案：按分区权重排序（保持核心章相对顺序不变）"""
           # 按 (是否为补充, 分区权重, 核心章原始顺序) 排序
           core_order = {ch["title"]: idx for idx, ch in enumerate(CORE_28_CHAPTERS)}
           
           def sort_key(item):
               title = item["title"]
               if item["is_core"]:
                   # 核心章：分区权重优先，同分区按原始顺序
                   zone_weight = self.ZONE_ORDER.get(item["zone"], 5)
                   core_idx = core_order.get(title, 999)
                   return (0, zone_weight, core_idx)
               else:
                   # 补充章：分区权重优先，同分区按标题排序
                   zone_weight = self.ZONE_ORDER.get(item["zone"], 5)
                   return (1, zone_weight, title)
           
           sorted_items = sorted(enriched, key=sort_key)
           return [item["original"] for item in sorted_items]
   ```
