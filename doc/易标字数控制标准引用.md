## 6. 口径收敛（与易标同源缺陷的本平台修复）

本平台历史上存在 **5 份同构的「有效目标字数」实现**（生成提示词 / 校验页 / 兜底扩写 /
压缩阈值 / SSE 落库），口径彼此分叉。已收敛为唯一权威实现
`backend/app/services/word_target_resolver.py`：

- `resolve_section_word_target(level, target_words, word_count_tier, writing_length, is_l3_own)`
  → 不可变 `SectionWordTarget{target, lo, hi, tolerance, source}`；
- 唯一优先级：`L1/L2 不参与 → target_words > word_count_tier > L3 自身正文 300±20% >
  全局 writing_length 档位 > 默认档位`；容差随「目标来源」走；
- 5 个历史消费点已全部转发该权威口径，并由
  `tests/test_word_target_resolver_2026_10_12.py` 的 `TestConsumerParity` 断言同口径。

## 8. 前端用户可见落点

- `frontend/src/pages/WordCountPage.tsx`：在「字数控制」卡片顶部渲染引用易标 R1–R15 标准
  的 `Alert` 说明（R2 万字单位 / R5 ±20% 强控 / R6·R8·R4 数量反推与页数 / R14 快照锚定 /
  R12 失败兜底 / R1 可读口径），并实时展示派生指标（每节 ±20% 区间、目标小节数、初稿目标、
  页数预估、R12 警告逐节明细）。
- `frontend/src/pages/OutlineEditorPage.tsx`：目录树下方渲染叶子（小节）数越界预警
  （R6/R7），基于 `getWordControlSettings` 返回的 `derived.leaf_outside_range` /
  `current_leaf_count` / `leaf_count_range`，手工编辑目录后提示「叶子数可能不符合字数控制预期」。
  预警在页面加载、删除节点、新增子目录、自动修复目录、最终审核确认保存后均会即时刷新
  （`refreshLeafWarn`），无需离开页面即可反映最新目录结构。
- `frontend/src/pages/SectionEditorPage.tsx`：选中 L3 单节时，若已生成正文字数落在达标区间
  （±20% / 四档 ±10%，由 `getWordCountRange` 计算）之外，渲染内联 `warning` 预警
  （R5/R12）：提示当前字数偏离区间，并说明强控下自动压缩/扩写、多轮后仍不达标则以
  「人工核对」警告呈现、不硬裁正文。
- `frontend/src/pages/WordControlHelpPage.tsx` + 路由 `/word-control-standard`：聚合展示
  易标 R1–R15 标准的独立帮助页，含分组速查与来源说明；`WordCountPage` / `OutlineEditorPage` /
  `SectionEditorPage` 均在相关卡片标题处提供「?」图标按钮跳转至此页。
