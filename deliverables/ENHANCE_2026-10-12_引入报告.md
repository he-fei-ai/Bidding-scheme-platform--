# ENHANCE 2026-10-12 引入报告

## 概述

本次引入基于 OpenBidKit 易标（参考软件）的方法论，为招投标方案平台补充 5 个新模块，
覆盖 P0/P1/E 三个优先级，共 13 项能力。所有新增功能均通过配置开关控制，
默认关闭（或按业务需要默认开启），不破坏现有功能。

## 新增模块清单

| 引入项 | 模块文件 | 功能 | 默认状态 |
|--------|----------|------|----------|
| P0-1 | `services/ai/outline_numbering.py` | 目录编号模板化引擎 | OFF |
| P0-2 | `services/ai/outline_alignment.py` | 目录一一对应模式 | OFF |
| P0-3 | `services/ai/prompt_layering.py` | 正文提示词分层消息栈 | OFF |
| P1-3 | `utils/text_edit.py` | 精确文本替换（唯一命中） | ON |
| E-2 | `services/ai/hazard_projects.py` | 六大类危大工程识别 | ON |

## 配置项清单（共 13 项）

### P0 优先级（必须引入）

1. **OUTLINE_NUMBERING_ENABLED** (bool, default: false)
   - 启用目录编号模板化
   - 启用后，目录节点会添加 `number` 和 `level` 字段

2. **OUTLINE_NUMBERING_TEMPLATE** (str, default: `{"1": "第{num}章", "2": "{num:1}.{num:2}", "3": "{num:1}.{num:2}.{num:3}"}`)
   - 编号模板 JSON
   - 支持占位符：`{num:N}`, `{zh}`, `{circled}`, `{alpha}`, `{roman}`, `{level:N}`, `{tail}`

3. **ALIGN_OUTLINE_TO_SCORING** (bool, default: false)
   - 启用目录一一对应模式
   - 启用后，L1 一级目录与评分项一一对应

4. **OUTLINE_MODE_DEFAULT** (str, default: `"standalone-technical"`)
   - 目录模式：`"standalone-technical"` | `"aligned"` | `"response-file"`

5. **SPLIT_PROMPT_LAYERS** (bool, default: false)
   - 启用分层消息栈
   - 启用后，正文生成使用 8 层消息栈结构

### P1 优先级（重要改进）

6. **PRE_PLAN_ILLUSTRATIONS** (bool, default: false)
   - 启用配图预编排（P1-1，模块待实现）

7. **MERMAID_REPAIR_ROUNDS** (int, default: 3)
   - Mermaid 修复轮次（P1-2，模块待实现）

8. **HTML_LAYOUT_REPAIR_ROUNDS** (int, default: 2)
   - HTML 布局修复轮次（P1-2，模块待实现）

9. **CONSISTENCY_UNIQUE_EDIT_STRICT** (bool, default: true)
   - 启用严格唯一命中替换
   - 启用后，`apply_text_edit` 要求 old_text 唯一命中

10. **OUTLINE_JSON_REPAIR_ROUNDS** (int, default: 3)
    - 目录 JSON 修复轮次（P1-4，模块待实现）

11. **CONTENT_JSON_REPAIR_ROUNDS** (int, default: 2)
    - 正文 JSON 修复轮次（P1-4，模块待实现）

### P2 优先级（增强功能）

12. **KNOWLEDGE_REFILL_TWO_ROUND** (bool, default: false)
    - 启用知识库两轮补漏（P2-2，模块待实现）

13. **KNOWLEDGE_REFILL_BATCH_SIZE** (int, default: 10)
    - 补漏分批大小

### E 优先级（业务增强）

14. **NINE_CHAPTER_CONTRACT_INJECT** (bool, default: true)
    - 启用九大章节契约注入（E-1）

15. **HAZARD_PROJECT_SCAN** (bool, default: true)
    - 启用危大工程扫描
    - 启用后，目录生成前扫描招标文件，识别危大工程类型

## 使用示例

### 1. 目录编号模板化

```python
from app.services.ai.outline_numbering import (
    NumberingTemplate,
    renumber_outline_with_template,
)

# 使用默认模板
template = NumberingTemplate.from_json(
    '{"1": "第{num}章", "2": "{num:1}.{num:2}", "3": "{num:1}.{num:2}.{num:3}"}'
)
outline, changed = renumber_outline_with_template(outline, template)

# 自定义模板（中文数字 + 圈号）
template_zh = NumberingTemplate.from_json(
    '{"1": "第{zh}章", "2": "{num:1}.{num:2}", "3": "（{zh}）"}'
)
outline, _ = renumber_outline_with_template(outline, template_zh)
```

### 2. 目录一一对应模式

```python
from app.services.ai.outline_alignment import align_outline_to_scoring

result = align_outline_to_scoring(
    outline=outline,
    scoring_text=scoring_text,  # 技术评分要求文本
    strict=False,  # False 返回 suggestions，True 抛出异常
)

if result.success:
    print("对齐成功")
else:
    print("对齐失败:", result.suggestions)
```

### 3. 分层消息栈

```python
from app.services.ai.prompt_layering import build_chapter_content_messages

messages = build_chapter_content_messages(
    system_rules="你是一个专业的工程标书撰写专家...",
    project_overview="项目概述...",
    global_facts="工期：90 天，金额：100 万元...",
    reference_material="参考素材...",
    plan_decision="本章需要包含表格和流程图...",
    parent_chapters="上级章节：1. 项目概述...",
    sibling_chapters="同级章节：1.1 项目背景...",
    current_section="1.2 工程范围\n字数要求：500-800 字",
)
```

### 4. 精确文本替换

```python
from app.utils.text_edit import apply_text_edit, apply_text_edits

# 单次替换（要求唯一命中）
result = apply_text_edit(text, "旧内容", "新内容")
if result.success:
    text = result.new_text
else:
    print("替换失败:", result.error)

# 批量替换
final_text, results = apply_text_edits(text, [
    {"old_text": "旧内容 1", "new_text": "新内容 1"},
    {"old_text": "旧内容 2", "new_text": "新内容 2"},
])
```

### 5. 危大工程识别

```python
from app.services.ai.hazard_projects import (
    scan_hazard_projects,
    build_hazard_outline_sections,
)

# 扫描招标文件
result = scan_hazard_projects(bid_text)
print("检测到的危大工程:", [hp.name for hp in result.detected])
print("建议章节:", result.suggested_sections)

# 生成专项章节节点
```

1. 所有新配置默认关闭（除 `CONSISTENCY_UNIQUE_EDIT_STRICT` 和 `HAZARD_PROJECT_SCAN` 默认开启）
2. 新模块是独立实现，不修改现有模块的核心逻辑

4. 所有新模块都有完整的单元测试覆盖

## 性能影响

1. `outline_numbering`：仅当 `OUTLINE_NUMBERING_ENABLED=true` 时执行，否则零开销
2. `outline_alignment`：仅当 `ALIGN_OUTLINE_TO_SCORING=true` 时执行
3. `prompt_layering`：仅当 `SPLIT_PROMPT_LAYERS=true` 时执行
4. `text_edit`：轻量级字符串操作，开销可忽略
5. `hazard_projects`：关键词匹配，单次扫描耗时 < 10ms
