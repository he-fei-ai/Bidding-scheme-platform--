## 3. 工作流程图

### 3.1 参考软件六步主链
```
STEP01 文档→Markdown(机械) → STEP02 招标解析(18项/6必填, 缓存预热)
      → STEP03 目录(V2七阶段 / 直出 / 弱模型稳定) → STEP04 全局事实(三模式)
      → STEP05 正文(编排→并发生成→表格清理→字数调整→配图→一致性审计)
      → STEP06 导出/扩写
```

### 3.2 目录生成闭环（易标）
```
初始生成 → JSON语法校验 → Schema校验 → 业务规则(叶子数/评分覆盖/去重/结构)
  → JSON修复(最小改动) → 分步拆分 → 模型审核(passed/simple_fix/user_feedback/user_refuse)
  → 反馈回灌+二次生成 → renumber编号统一 → saveOutline(reason协议)落库
```

### 3.3 正文生成与配图闭环（易标）
```
收集叶子 → 编排(选 knowledge.item_ids/facts.titles/table/writing_focus)
  → 并发生成(16规则, text并发10) → 表格转文字 → 字数调整(锚点唯一命中)
  → 配图预编排(html>ai>mermaid, limit/priority/occupied互斥/标题去重)
  → 配图生成(AI/HTML截图/Mermaid+本地渲染校验+修复循环)
  → 一致性审计(300k字分组) → 唯一命中修复/Agent修复 → 原方案覆盖审计
```

### 3.4 缓存顺序优化（贯穿全链）
```
[稳定大块前置] system → 招标原文/项目概述 → 全局事实清单 → 目录树
[任务差异置后] 当前分支/当前章节/额外要求
projectOverview 先行 → wait 5s → 其余并发，放大前缀命中（成本↓约10×）
```
