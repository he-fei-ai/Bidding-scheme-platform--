今天是第二期，根据解析好的项目概述和技术评分需求，生成投标文件提纲：

一份好的标书，提纲是关键，而生成好的提纲，则有以下几个难点：
- **格式化输出**：为了生成正文时，AI能够很好的理解提纲，保证结构不错乱，那么提纲必须是格式化的
- **超出AI输出长度**：几十万字的标书，提纲也不会短，现在AI虽然都号称几十万的上下文，但实际输出也就2千字左右，无法直接完整的长提纲
- **提纲可编辑**：虽然AI能生成比较不错的提纲，但还是没法100%满足要求，所以提纲必须是可编辑的，而且编辑后还不能破坏原有的结构

下面，咱们就来逐项分析一下，如何解决上述难点。

# 二、长标书+普通AI模型（增强版 V3.0——双轨制生成）

要想使用如 `glm-4-air` 这样低价的普通模型，也能生成几十万字标书需要的长提纲，那实现起来就复杂多了。

**限制**
1. 上下文短，仅能输出1500字左右
2. 输出结果不稳定，尤其是json这类结构化数据，可能出现格式错误

**核心设计原则（V3.0 铁律）**
1. **基石永固**：将《技术标—施工组织设计目录生成样本》中的28章一级目录作为不可删减的固定模板（第一轮初稿）。
2. **只增不减**：第二轮根据项目摘要、评分要求生成的目录，**仅允许作为新增章节补充**，严禁删除、跳过或修改28章中的任何一章。
3. **顺序不乱**：28章的原始顺序（第1章→第28章）必须严格保留。补充章节只能“插入”到合适的位置，但不得打乱原有章节的先后次序。

**整体思路（V3.0 双轨合并）**
1. 第一轮：加载固定的28章一级目录（初稿）。
2. 第二轮：AI根据项目概述、评分要求，生成“补充一级目录”（只识别模板未覆盖的新增章节）。
3. 合并（智能插入）：将补充章节插入到28章中合适的位置（如“智慧工地”插入第10章附近），但保持28章原有的1→28顺序不变。
4. 生成二三级目录：遍历合并后的一级列表，逐个生成其下的二级、三级目录（强制最小节点数）。

## 第三部分：智能合并（保持28章顺序绝对不变）

此步将第一部分（28章）与第二部分（补充列表）合并。合并算法保证**28章的相对顺序严格不变**，补充章节按语义插入到最合适的位置。

**合并策略（代码实现）**：

```python
from typing import List, Dict

def merge_outline_with_supplements(fixed_28: List[Dict], supplements: List[Dict]) -> List[Dict]:
    """
    智能合并：保持28章顺序不变，将补充章节插入合适位置。
    """
    # 构建插入映射：根据建议插入位置，将补充项分类
    insert_map = {f"第{i}章": [] for i in range(1, 29)}
    insert_map["末尾"] = []
    
    for supp in supplements:
        target = supp.get('suggested_insert_after', '末尾')
        # 简单匹配逻辑：如果建议插在某章之后，归入该章分组
        matched = False
        for idx, ch in enumerate(fixed_28):
            if target in ch['title'] or ch['title'] in target:
                insert_map[f"第{idx+1}章"].append(supp)
                matched = True
                break
        if not matched:
            insert_map["末尾"].append(supp)
    
    # 构建最终列表：遍历28章，每章后面插入其对应的补充项
    merged = []
    for idx, ch in enumerate(fixed_28):
        merged.append(ch)  # 先加固定章
        # 插入该章后面的补充项
        for supp in insert_map.get(f"第{idx+1}章", []):
            merged.append({
                "id": None,  # 后续重新编号
                "title": supp['title'],
                "fixed": False,
                "source": "supplement"
            })
    
    # 处理末尾补充
    for supp in insert_map.get("末尾", []):
        merged.append({
            "id": None,
            "title": supp['title'],
            "fixed": False,
            "source": "supplement"
        })
    
    # 重新编号（id重置为1,2,3...）
    for idx, item in enumerate(merged, start=1):
        item['id'] = str(idx)
    
    return merged
```

## 第四部分：生成二级/三级目录（强制最小节点数 + 第七章特殊处理）

此步骤沿用增强版 V2.0 的策略，但增加一条：**对于固定保留的28章中完全不涉及的项目内容（如无PC工程），其二级目录描述可标注“（本项目不涉及）”，但二级节点仍需保持最小数量（≥2个），以确保结构完整。**

### 节点分布生成（强制最小数）

```python
import random

def generate_nodes_distribution(level1_count, min_level2=2, min_level3=2):
    """
    为每个一级节点生成二级数量和每个二级下的三级数量。
    保证最低数量，并增加随机增量使结构更自然。
    """
    distribution = []
    for _ in range(level1_count):
        level2_count = min_level2 + random.randint(0, 3)
        leaf_distribution = []
        for _ in range(level2_count):
            leaf_count = min_level3 + random.randint(0, 2)
            leaf_distribution.append(leaf_count)
        distribution.append({
            'level2_count': level2_count,
            'leaf_per_level2': leaf_distribution
        })
    return distribution
```

### 第七章（主要分部工程施工方法）的特殊处理

此章的二级目录必须严格来自项目解析的 **“承包范围/承包内容”** ，不得AI凭空捏造。

```python
def generate_chapter7_children(scope_list):
    """
    根据承包范围列表生成第七章的二级目录框架
    """
    children = []
    for idx, item in enumerate(scope_list, start=1):
        children.append({
            "id": f"7.{idx}",
            "title": f"{item}工程",
            "description": "",
            "children": []  # 三级留空，后续AI补全
        })
    # 若scope_list为空，则补2个默认占位二级，避免结构空洞
    if not children:
        children = [
            {"id": "7.1", "title": "（根据项目承包范围确定）", "description": "", "children": []},
            {"id": "7.2", "title": "（根据项目承包范围确定）", "description": "", "children": []}
        ]
    return children
```

## 完整流程代码示例（Python 整合）

```python
class OutlineGeneratorV3:
    def __init__(self):
        self.fixed_28 = FIXED_28_CHAPTERS  # 导入上述固定列表
    
    def generate(self, overview, requirements, scope_list):
        # 1. 第一轮：固定28章（初稿）
        first_round = self.fixed_28.copy()
        
        # 2. 第二轮：AI生成补充目录（仅新增）
        supplements = self.call_ai_supplements(overview, requirements, self.fixed_28)
        
        # 3. 智能合并（28章顺序绝对不变）
        merged_outline = self.merge_with_fixed_order(first_round, supplements)
        
        # 4. 生成节点分布（强制最小数）
        dist = generate_nodes_distribution(len(merged_outline))
        
        # 5. 遍历生成二三级
        full_outline = []
        for idx, l1_node in enumerate(merged_outline):
            if l1_node['title'] == '主要分部工程施工方法':
                # 第七章特殊处理
                framework = self.build_chapter7_framework(scope_list, idx+1)
            else:
                framework = self.build_framework(l1_node, dist[idx])
            
            # AI补全二三级
            completed = self.call_ai_fill_with_retry(framework, overview, requirements)
            full_outline.append(completed)
        
        return {"outline": full_outline}
```
