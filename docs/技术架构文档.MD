### 2.2 核心设计模式

#### 2.2.1 Provider 工厂模式
```python
# provider_factory.py
def get_working_provider(ai_config: dict) -> tuple[Provider, str]:
    """
    优先级链：
    1. 当前保存的配置（ai_config 表）
    2. 最近使用的提供商（provider_history 表）
    3. 内置兜底提供商（Agnes/DeepSeek/SiliconFlow/通义/智谱）
    """
```

#### 2.2.2 Prompt 注册表模式
```python
# _registry.py
_ALL_PROMPTS: dict[str, dict] = {}

def _reg(key: str, category: str, label: str, value: str) -> str:
    """注册提示词并自动提取变量"""
    variables = extract_variables(value)  # {var} 和 __CONSTANT__
    _ALL_PROMPTS[key] = {
        "category": category,
        "label": label,
        "content": value,
        "variables": variables,
    }
    return value
```

#### 2.2.3 自适应并发控制
```python
# workflows.py
class AdaptiveConcurrencyController:
    """根据 AI 响应时间动态调整并发数"""
    target_latency = 8.0  # 目标延迟（秒）
    
    def _adjust(self):
        if avg_latency > target * 1.5:
            self.max_concurrency -= 1  # 降速
        elif avg_latency < target * 0.5:
            self.max_concurrency += 1  # 加速
```

#### 2.2.4 AI 熔断器（AnalysisCircuitBreaker）
```python
# workflows.py
class AnalysisCircuitBreaker:
    """连续失败时熔断，冷却后自动恢复"""
    failure_threshold = 2      # 连续失败次数触发熔断
    cooldown_seconds = 5       # 冷却时间
    
    # 状态转换：CLOSED → OPEN → HALF_OPEN → CLOSED
```

### 3.2 核心组件

#### 3.2.1 SectionEditorPage（章节编辑器）
- **状态管理**: Zustand store
- **核心功能**:
  - 章节树渲染（递归组件）
  - SSE 事件处理（onmessage/onerror/abort）
  - 批量树更新防抖（50ms flushTreeUpdates）
  - 字数预算去重（监听 tree.length 变化）
  - 暂停/恢复/停止生成控制

#### 3.2.2 OutlineEditorPage（大纲编辑器）
- **核心功能**:
  - EventSource 连接（目录生成）
  - 参考提纲上传
  - V5.1 重构模式切换

#### 3.2.3 RejectionCheckPage（废标项检查）
- **核心功能**:
  - 检查清单管理（通用 + 项目定制）
  - 三级检查流程：清单 → 检查 → 分析
  - 风险等级可视化（高/中/低）
  - 修改建议生成

#### 3.2.4 ConsistencyPage（全文一致性审计）
- **核心功能**:
  - 招标要求 vs 投标响应比对
  - 评分标准对齐度分析
  - 响应完整性检查
  - 一致性评分（0-100）

## 七、性能优化策略

### 7.1 数据库层
- **连接池**: 带死线程检测的 `create_async_engine`
- **批量操作**: 章节列表一次性加载，避免 N+1 查询
- **索引**: `sections.project_id`, `sections.parent_id`

### 7.2 AI 调用层
- **缓存**: `_ai_config_cache` with RLock（TTL 1 小时）
- **降级**: 多供应商自动切换
- **并发**: `AdaptiveConcurrencyController` 动态调整
- **熔断**: `AnalysisCircuitBreaker` 连续失败自动保护
- **超时**: 单请求 900s + SSE 总超时 2700s

### 7.3 导出层
- **V7.0 指纹缓存**: 内容 MD5 指纹匹配直接复用
- **图表缓存**: `_EXPORT_CACHE_DIR` 持久化 PNG
- **流式响应**: 大文件分块传输

### 7.4 前端层
- **批量更新**: 50ms 防抖合并 SSE 事件
- **防重复请求**: 监听 `tree.length` 变化，避免生成期间重复请求
- **AbortController**: 支持中断 SSE 连接
- **GPU 加速**: 提示用户开启硬件加速

## 八、安全设计

### 8.1 数据加密
```python
# 使用 cryptography 库 AES-256-CBC 加密 API Key
from cryptography.fernet import Fernet

def encrypt_api_key(plaintext: str) -> str:
    f = Fernet(key)
    return f.encrypt(plaintext.encode()).decode()

def decrypt_api_key(encrypted: str) -> str:
    f = Fernet(key)
    return f.decrypt(encrypted.encode()).decode()
```

## 十、Agent 工作流架构

### 10.1 多 Agent 协调
```
                    ┌─────────────────┐
                    │   Orchestrator  │
                    │  (主调度 Agent)  │
                    └────────┬────────┘
                             │
        ┌────────────────────┼────────────────────┐
        │                    │                    │
        ▼                    ▼                    ▼
┌───────────────┐   ┌───────────────┐   ┌───────────────┐
│ Tender Agent  │   │ Outline Agent │   │  Content Agent │
│ 招标文件解析   │   │  目录生成      │   │  正文生成      │
└───────────────┘   └───────────────┘   └───────────────┘
        │                    │                    │
        └────────────────────┼────────────────────┘
                             ▼
                    ┌─────────────────┐
                    │  Review Agent   │
                    │  审核报告生成    │
                    └─────────────────┘
```

### 10.2 Agent 输入输出规范
```json
{
  "payload": {
    "task": "agent任务描述",
    "input_files": ["tender.md", "current-outline.json"],
    "output_file": "agent-result.md",
    "recovery_reason": "恢复触发原因（可选）"
  }
}
```

### 10.3 典型 Agent 工作流
1. **招标文件解析 Agent**: 提取项目信息、评分标准、废标条款
2. **目录生成 Agent**: 基于评分标准生成对齐的目录结构
3. **正文生成 Agent**: 逐章生成符合字数要求的内容
4. **审核报告 Agent**: 综合检查生成最终审核报告
