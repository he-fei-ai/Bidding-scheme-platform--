# 图表生成与校验规则用户文档 (2026-10-17)

## 一、支持的图表类型

| 类型 | 数据格式 | 生成方式 | 校验规则 |
|---|---|---|---|
| **flowchart** | Mermaid 流程图代码 | AI 生成 Mermaid 代码 | 语法校验 + 结构完整性 |
| **gantt** | Mermaid 甘特图代码 | AI 生成 Mermaid 代码 | 语法校验 + 任务依赖检查 |
| **architecture** | JSON 树形结构 `{"type":"architecture","tree":{...}}` | AI 生成 JSON | v3.1 结构校验（深度/节点数/子类型） |
| **labor** | JSON 矩阵 `{"phases":[],"categories":[],"data":[[]]}` | AI 生成 JSON | v3.1 维度一致性校验 |
| **timeline** | JSON 时间线 `{"milestones":[{"date":"...","title":"..."}]}` | AI 生成 JSON | v3.1 日期顺序校验 |
| **comparison** | Mermaid 饼图代码 或 JSON `{"rows":[...]}` | AI 生成 Mermaid/JSON | 百分比之和校验 |
| **layout** | JSON 布局 `{"zones":[{"name":"...","x":0,"y":0,"w":100,"h":100}]}` | AI 生成 JSON | v3.1 几何重叠/越界校验 |

---

## 二、图题四级优先级

导出时图题按以下优先级选取（从高到低）：

1. **载荷 title/caption**：AI 生成的 chart-json 中的 `title` 或 `caption` 字段
2. **Mermaid title**：Mermaid 代码中的 `title "xxx"` 行
3. **引导语 caption_hint**：围栏前一行符合引语特征的短句（≤50 字符，以标点结尾）
4. **类型通用名**：`_CHART_TYPE_MAP` 中的默认名称（如"流程图"、"甘特图"）

**示例**：
```markdown
施工总进度计划安排如下：

```mermaid
gantt
    title 施工进度计划
    ...
```
```
→ 图题：`施工进度计划`（取自 Mermaid title）

```markdown
劳动力计划如下：

```chart-json
{"type":"labor","title":"各阶段劳动力投入"}
```
```
→ 图题：`各阶段劳动力投入`（取自载荷 title）

## 三、校验报错说明

### 3.1 架构图 (architecture)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `缺少根节点标签` | `tree.label` 或 `tree.name` 为空 | 为根节点添加 label 字段 |
| `架构深度超过5层限制` | 树深度 > 5 | 减少层级或使用子图 |
| `检测到同级重复标签` | 同一层级有相同 label | 修改标签使其唯一 |
| `{subtype}类型最少需N个节点` | 节点数 < 下限 | 增加节点 |
| `{subtype}类型最多N个节点` | 节点数 > 上限 | 拆分或简化 |

**子类型检测关键词**：
- `organization`：组织、部门、岗位、负责人、经理
- `wbs`：WBS、工作包、任务分解、工序
- `system`：系统、模块、软件、平台、架构
- `infrastructure`：网络、服务器、设备、拓扑

### 3.2 甘特图 (gantt)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `必须包含至少一个任务` | tasks 为空 | 添加任务 |
| `检测到重复的任务ID` | 多个任务同 ID | 修改 ID 使其唯一 |
| `任务 X 的依赖项 'Y' 不存在` | 依赖项 ID 无效 | 检查依赖项 ID 是否存在 |

### 3.3 流程图 (flowchart)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `流程图必须至少包含2个节点` | 节点数 < 2 | 添加更多节点 |
| `节点ID 'xxx' 包含非ASCII字符` | ID 含中文/特殊字符 | 使用 ASCII ID（如 A、B、C） |
| `检测到孤立节点` | 节点未在任何连线上 | 添加连线或移除孤立节点 |

### 3.4 时间线 (timeline)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `timeline.milestones 必须是 ≥2 个事件的列表` | 里程碑 < 2 | 添加更多里程碑 |
| `timeline.milestones[i] 缺少 date 或 title` | 字段缺失 | 补全 date 和 title |
| `时间线日期逆序` | 日期非升序 | 调整日期顺序 |

### 3.5 劳动力图 (labor)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `必须包含 phases 字段` | phases 缺失 | 添加阶段列表 |
| `必须包含 categories 字段` | categories 缺失 | 添加工种列表 |
| `维度不一致：第N个阶段数据仅有X个值但有Y个工种` | 行/列不匹配 | 修正数据矩阵 |
| `数据矩阵有X行但阶段有Y个` | 行数 ≠ 阶段数 | 修正矩阵行数 |
| `第N个阶段(...)所有工种数值为0` | 全零行 | 添加实际数据或移除该阶段 |

### 3.6 布局图 (layout)

| 错误信息 | 原因 | 修复建议 |
|---|---|---|
| `必须包含至少一个区域` | zones 为空 | 添加区域定义 |
| `区域 N 缺少有效名称` | name/label/title 为空 | 为区域添加名称 |
| `布局图区域 'X' 坐标越界` | x/y/w/h 超出 100×100 画布 | 调整坐标或尺寸 |
| `布局图区域 'X' 与 'Y' 重叠` | 两个区域相交 | 调整位置使其不重叠 |

## 四、降级行为说明

### 4.1 渲染失败处理

| 场景 | 行为 | 说明 |
|---|---|---|
| Mermaid HTTP Service 失败 | 自动降级到 PIL v2 渲染 | 2.5x 超采样 300DPI |
| PIL v2 也失败 | 跳过该图表，不占图号 | 无占位符（默认） |
| `CHART_FAIL_PLACEHOLDER=true` | 显示灰色排错说明 | 需显式开启 |

### 4.2 围栏块处理

| 场景 | 行为 | 说明 |
|---|---|---|
| Mermaid 语法错误 | repair_mermaid 尝试修复（11 步） | 修复失败则删除块 |
| chart-json 校验失败 | 仅记录 WARNING 日志 | 不删除块，交渲染层处理 |
| 未闭合围栏 | 定位后兜底闭合 | 保留正文段落 |
| xychart/journey 类型 | 重定向到 comparison/flowchart 通道 | 不误判为坏块 |

### 4.3 图号管理

| 场景 | 行为 | 说明 |
|---|---|---|
| 渲染成功 | 分配图号 `图{章}-{序}` | 正常递增 |
| 渲染失败 | 回滚图号，不占号 | 下一张图拿到连续号 |
| 章节级失败快照 | 快照/还原计数器 | 防止断档 |
| 预渲染 | 不占图号 | 仅生成不计数 |

## 五、缓存与性能

| 机制 | 说明 |
|---|---|
| L1 内存缓存 | 存 immutable bytes，线程安全 |
| 磁盘缓存 V6.0 | 项目分桶，60s 失败冷却 |
| Single-flight | 同键并发只渲染一次 |
| 缓存键归一化 | 剔除图号 + sort_keys |

## 六、快速故障排查

```
问题：图表静默丢失
→ 检查日志：[图表校验] chart-json 块 v3.1 结构校验未通过
→ 检查日志：[Mermaid修复] step=N 修复了 XXX

问题：图题显示类型通用名
→ 检查载荷是否有 title 字段
→ 检查 Mermaid 代码是否有 title 行
→ 检查围栏前是否有引导语

问题：图号不连续
→ 检查是否有渲染失败的图表
→ 查看 _rewind_figure_number 调用日志

问题：架构图误报「缺少根节点标签」
→ 已修复：统一闸门调用 validate_chart_payload（含 tree 解包）
```
