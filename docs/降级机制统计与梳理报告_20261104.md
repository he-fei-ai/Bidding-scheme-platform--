## 8. 仍存在的限制

1. **无真实 API Key**：文本模型链路仅以假 Provider / mock 验证（场景路由、降级链、熔断冷却、审计回滚），**未跑真实模型链路**，不能声称已验证真实 API 行为。
2. **PDF 转换依赖外部环境**：本机无 LibreOffice（也无 docx2pdf/Word COM），真实转换用例跳过；已验证不可用时返回 `PdfUnavailable → 501`，不会静默失败或产出损坏文件。
3. **OCR 引擎依赖外部组件**：MinerU/rapidocr/tesseract 任一缺失时按链回退；全不可用时返回空文本，靠 `parse_quality` 标记与前端告警，无法恢复图片内容。
4. **图表渲染依赖 PIL / 外部 HTTP 服务**：两层都不可用时退化为占位符/纯文本。
5. **Redis 缺失**：回退进程内缓存，多实例一致性无法保证。
6. **前端 SSE「任务已死但仍在重连」**：超时只发 `sse_timeout` 并提示重连，若后台任务实际已终止，前端需靠任务状态查询兜底，当前无自动降级为失败态。
7. **少量低风险静默点保留**：`sse_content.py:1067` 临时态清理、`image_engine.py:724` 指标统计、`workflows_word_adjust.py:197` 微调失败、`prompts/_governance.py:159-166` 治理配置回落默认、`prompt_layering.py` 分层失败——均不影响交付物或默认值等价现状，为避免改动正常路径行为未做变更。
